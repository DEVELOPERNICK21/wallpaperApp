# 📦 Install react-native-view-shot for Calendar Wallpaper Feature

## Quick Install

```bash
npm install react-native-view-shot
# or
yarn add react-native-view-shot
```

## iOS Setup

```bash
cd ios
pod install
cd ..
```

## Android Setup

No additional setup needed (auto-linked)

## Rebuild App

```bash
# Android
npm run android

# iOS
npm run ios
```

## Verify Installation

The Year Calendar component will automatically detect if the package is installed and enable wallpaper functionality.

---

**Note:** The calendar will work without this package, but wallpaper setting feature requires it.
